# XiaoT 的 Muvyo 插件仓库

个人维护的 [Muvyo](https://) 第三方插件集合，均由本人自用场景打磨而来，签名后以插件仓库形式分发。

## 插件列表

### 磁力搜索引擎 · `newvectors.magnet-search`

在 Muvyo 订阅剧集搜索 / 资源搜索时，按**你自己配置的磁力站规则**（XPath / 正则）并行抓取多个站点，解析出 **标题 / 大小 / 时间 / 磁力链接** 返回给 Muvyo 展示，命中订阅后可联动离线下载。

- 最低 Muvyo 版本：v3.12.9+
- **📖 详细使用说明**：[plugins/newvectors.magnet-search/README.md](./plugins/newvectors.magnet-search/README.md)

> 插件**不内置任何磁力站**，完全由你在设置里填写的 `site_rules` 驱动。插件 README 内附有可用站点的规则 JSON 模板，复制粘贴即可启用。

## 安装

1. 打开 Muvyo → **第三方插件 → 插件仓库**
2. 添加本仓库地址：`https://github.com/newvectors/muvyo-magnet`
3. 在列表中找到「磁力搜索引擎」→ 安装
4. 进入插件设置，粘贴磁力站规则 JSON 并启用
