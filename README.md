# XiaoT 的 Muvyo 插件仓库

个人维护的 Muvyo 第三方插件集合，均由本人自用场景打磨而来，签名后以插件仓库形式分发。

仓库里只放**加密签名后的产物**（`index.json` + `plugins/`），插件源码不上传。

## 插件列表

### 权益宝 · `newvectors.quanyibao`

对接 [权益宝](https://www.quanyibao.com) 的资源搜索插件：搜片名 → 找到该影片的资源帖 → 用账号积分解锁 → 把 **115 网盘分享链接与提取码**交给 Muvyo 转存。

支持多账号（一行一个「账号|密码」）、保存设置即逐个测试登录并显示各账号剩余积分、每日定时签到轮换、买片时积分不够自动换下一个账号。每次取链前都会先读服务端的解锁状态，**已解锁的直接取链，不会重复扣分**；购买超时等不确定情况会提示你到站点核对，不会自动重试。所有报错都写进 Muvyo 插件日志，并写明出错步骤与接口。

- 最低 Muvyo 版本：v3.13.2+
- 需要自备权益宝账号；按次购买会消耗账号积分
- **📖 详细使用说明**：[plugins/newvectors.quanyibao/README.md](./plugins/newvectors.quanyibao/README.md)

### 磁力搜索引擎 · `newvectors.magnet-search`

在 Muvyo 订阅剧集搜索 / 资源搜索时，按**你自己配置的磁力站规则**（XPath / 正则）并行抓取多个站点，解析出 **标题 / 大小 / 时间 / 磁力链接** 返回给 Muvyo 展示，命中订阅后可联动离线下载。

- 最低 Muvyo 版本：v3.12.9+
- **📖 详细使用说明**：[plugins/newvectors.magnet-search/README.md](./plugins/newvectors.magnet-search/README.md)

> 插件**不内置任何磁力站**，完全由你在设置里填写的 `site_rules` 驱动。

## 安装

1. 打开 Muvyo → **第三方插件 → 插件仓库**
2. 添加本仓库地址：`https://github.com/newvectors/xiaot-muv_plugins`
3. 在插件列表里选择需要的插件安装：
   - 「权益宝」→ 安装 → 设置里填账号密码（多个账号一行一个）→ 保存即自动登录并显示积分
   - 「磁力搜索引擎」→ 安装 → 设置里粘贴磁力站规则 JSON 并启用
4. 装完到插件的「定时任务」里按需要开启「每日积分签到」（权益宝）

## ⚠️ 风险与合规提醒

- 本仓库插件仅提供**搜索、解析与接口对接能力**，不内置、不托管任何影视资源或磁力链接
- 请自行确认所在国家 / 地区关于版权、网络访问和内容下载的法律法规，**仅用于合法合规的资源获取**
- 请勿搜索、下载、传播受版权保护的影视、音乐、软件等内容，相关责任由使用者自行承担
- 站点规则由用户自行配置并对可用性负责；站点失效属正常现象，更新规则即可
- **权益宝插件的积分购买走站点官方接口，按次扣除你自己账号的积分**；账号密码只存在本机 Muvyo，但请自行评估凭据落地本机的风险，建议使用单独账号
- 各插件均与对应站点官方无关，未获其授权；接口变更导致失效不另行承诺
