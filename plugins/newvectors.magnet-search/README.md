# newvectors.magnet-search — Muvyo 磁力搜索引擎插件

在 Muvyo 订阅剧集搜索 / 资源搜索时，按**你配置的磁力站规则**抓取网页，用 XPath / 正则解析出**标题、大小、时间、磁力链接**，返回给 Muvyo 展示，命中订阅后自动**转存或离线下载**到网盘。

- 插件 ID：`newvectors.magnet-search`
- 作者：`XiaoT`
- 最低版本：Muvyo 3.13.2+

> 本插件**不内置任何磁力站**，搜索完全依赖你在插件设置里填写的站点规则（`site_rules`）。请先完成配置再使用；未配置时搜索会直接提示错误。

## 功能概览

- **多站并行搜索**：同时抓取多个磁力站，结果按站点轮询混合返回，总耗时≈最慢单站。
- **规则自定义**：用 XPath / 正则提取标题、大小、时间、磁力链接，适配任意列表型磁力站。
- **系统代理支持**：访问被墙站点时一键开启走 Muvyo 系统代理。
- **智能标题整理**：自动识别分辨率（1080P / 4K / 720P）、季集数（S01 / E100）并统一格式化，方便 Muvyo 识别匹配。
- **失败静默**：单站失败只在日志记录，不打扰搜索结果页。
- **资源占用可调**：并行抓取数可在 1–8 间调整，低配设备也能流畅使用。

## 一、安装

1. 打开 Muvyo 客户端，进入「**第三方插件 → 插件仓库**」。
2. 添加本插件的 GitHub 仓库地址，列表里找到「磁力搜索引擎」，点击**安装**。
3. 安装时按提示确认联网范围与授权。
4. 安装完成后，在插件设置里填写磁力站规则（见下）并启用。

> 安装后如插件有更新，在插件仓库刷新即可获取新版本。

## 二、配置项

在插件设置页填写：

| 配置项 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `site_rules` | 文本(JSON) | 空 | **必填**。磁力站规则数组，每个站点一个对象；也可以直接粘贴单个站点对象 `{...}`，会自动生效。`search_url` 缺 `https://` 会自动补全 |
| `use_proxy` | 开关 | 关 | **走系统代理**：开启后抓取经 Muvyo 系统设置里配置的代理发出。访问被墙站时打开；直连能通的站不需要开 |
| `max_concurrency` | 数字 | `4` | **最多并行抓取数**：同时抓取多少个站点，范围 1–8。越大越快但占用资源多，配置较低的设备建议调小（如 2）避免卡顿 |
| `max_pages` | 数字 | `1` | 每个站点最多翻页数，范围 1–5 |
| `max_items` | 数字 | `20` | 每个站点最多返回条数，范围 1–50 |

`site_rules` 填写示例（单站）：

```json
[
  {
    "name": "示例站",
    "search_url": "https://example.com/search/page/{page}?keyword={keyword}",
    "list_xpath": "//tbody/tr",
    "fields": {
      "title": { "xpath": "./td[2]//text()", "join": "" },
      "link": { "xpath": "./td[3]//a[starts-with(@href,'magnet:')]/@href", "index": 0 },
      "size": { "xpath": "./td[4]/text()", "index": 0 },
      "time": { "xpath": "./td[5]/text()", "index": 0 }
    },
    "next_page": { "mode": "xpath_text", "xpath": "//ul[@class='pagination']//a/text()", "contains": ["Next"] }
  }
]
```

多站：在数组里并列多个对象即可，插件会对**每个站点独立搜索**，结果按站点轮询混合返回。

> 示例中 `example.com` 等域名仅作结构示意，实际填写时请使用插件「已授权域名」列表内的站点，或提 Issue 申请添加后使用。

## 三、规则参数详解

每个站点规则是一个对象，字段如下：

### 1. `name`（必填）
站点显示名，会作为结果的来源标识展示。

### 2. `search_url`（必填）
搜索页地址模板，支持两个占位符：

| 占位符 | 替换规则 | 示例 |
|---|---|---|
| `{keyword}` | URL 编码后的搜索词 | `海贼王` → `%E6%B5%B7%E8%B4%BC%E7%8E%8B` |
| `{page}` | 当前页码，从 1 开始 | 第 2 页 → `2` |

> ⚠️ 域名必须在插件「已授权域名」列表内，否则插件无法访问该站点。

### 3. `list_xpath`（必填）
定位**结果行**的 XPath，页面中每个命中节点 = 一条搜索结果。例如常见列表站每行是一个 `<tr>`：

```
//tbody/tr
```

### 4. `fields`（title / link 必填）

对每一行进一步提取字段：

| 字段 | 必填 | 含义 | 说明 |
|---|---|---|---|
| `title` | ✅ | 资源标题 | 截断到 500 字符 |
| `link` | ✅ | 磁力链接 | 必须以 `magnet:?` 开头，否则该行被跳过 |
| `size` | 可选 | 文件大小 | 自动换算为字节数（支持 B/KB/MB/GB/TB 及 KiB/MiB/GiB/TiB） |
| `time` | 可选 | 发布时间 | 作为结果发布时间，截断到 40 字符 |

#### 字段算子（通用，可选）

| 算子 | 类型 | 作用 | 示例 |
|---|---|---|---|
| `xpath` | 文本 | 必填，取值表达式 | `"./td[4]/text()"` |
| `index` | 数字 | 取第几个值（0 起；负数倒数，`-1` = 最后一个） | `0` / `-1` |
| `join` | 文本 | 命中多个值时用该分隔符拼接（优先于 index） | `""` 直接拼、`" "` 空格拼 |
| `regex` | 文本 | 正则提取，取第 1 个捕获组 | `"\\[([0-9A-Za-z]+)\\]"` |
| `template` | 文本 | 模板包装，`{value}` 替换为提取值 | `"https://example.com/view/{value}"` |
| `replace` | 数组 | 逐对字符串替换 `[["旧","新"],...]` | `[["/","-"]]` |
| `default` | 文本 | 提取为空/失败时的兜底值 | `"未知"` |
| `strip` | 布尔 | 是否去除首尾空白，默认 `true` | `false` |

**处理顺序**：`regex → template → replace → strip → default(空值兜底)`。

### 5. `next_page`（可选）
翻页判断，四种模式：

| 模式 | 行为 | 需要字段 |
|---|---|---|
| `always` | 恒有下一页（受 `max_pages` 限制） | 无 |
| `never` | 不翻页 | 无 |
| `xpath_exists` | XPath 命中节点即翻页 | `xpath` |
| `xpath_text` | XPath 文本命中 `contains` 任一关键词即翻页 | `xpath` + `contains` |

## 五、XPath 语法

插件内置轻量解析引擎，支持以下语法：

| 语法 | 含义 | 示例 |
|---|---|---|
| `//` | 后代轴（任意深度） | `//tbody/tr` |
| `/` | 子轴 | `./td[4]` |
| `./` | 相对当前节点 | `./a/@href` |
| `text()` | 取文本（含子树递归拼接） | `./td[1]/span/text()` |
| `@attr` | 取属性 | `./a/@href` |
| `*` | 任意元素 | `./td/*/text()` |
| `[N]` | 第 N 个子节点（1 起） | `td[4]` |
| `[last()]` | 最后一个 | `td[last()]` |
| `[@class='x']` | 属性等于 | `a[@class='download']` |
| `[@attr]` | 属性存在 | `a[@href]` |
| `[starts-with(@attr,'x')]` | 属性前缀 | `a[starts-with(@href,'magnet')]` |
| `[contains(@attr,'x')]` | 属性包含 | `a[contains(@class,'magnet')]` |
| `[contains(text(),'x')]` | 文本包含 | `span[contains(text(),'番')]` |

正则提取请用字段级 `regex` 算子，与 XPath 相互独立、可组合使用。

## 六、使用与测试

1. 安装启用插件，在设置里把规则 JSON 数组粘贴到 `site_rules`。
2. （可选）访问被墙站时打开「走系统代理」开关，并在 Muvyo 系统设置里配好代理。
3. （可选）设置「最多并行抓取数」：低配设备建议 `2`，追求速度可保持 `4`。
4. 在 Muvyo **资源搜索**里搜一个关键词（如「海贼王」）。
5. 若返回磁力结果，说明插件正常工作，每条结果含标题、大小、发布时间、磁力链接。
6. 命中订阅后，Muvyo 会自动把磁力链接转存或离线下载到网盘。

**排查顺序**：① 规则是否填写且为合法 JSON 数组 → ② 域名是否在授权列表 → ③ 用浏览器打开 `search_url` 实际地址确认可达（被墙站记得开代理）→ ④ `list_xpath` 是否命中行 → ⑤ 字段 `xpath` 是否取到值 → ⑥ `link` 是否 `magnet:?` 开头。

## 七、常见问题

**Q1：搜索报错「磁力站规则不可用」？**
说明 `site_rules` 为空、JSON 解析失败或没有有效规则，错误信息会写明具体原因。请按提示修正后保存。

**Q2：搜索没有结果？**
先确认规则已填写且是合法 JSON 数组；再看 Muvyo 插件日志——站点失败会提示具体原因（HTTP 状态 / 超时 / 未解析到结果行）。被墙站记得开「走系统代理」。

**Q3：能搜到但磁力链接为空？**
`link` 字段 XPath 未命中磁力链接节点，调整 `link.xpath`。

**Q4：可以配置任意网站吗？**
不能。域名必须在插件「已授权域名」列表内（这是 Muvyo 的安全机制）。需要新增站点请在插件仓库提 Issue。

**Q5：并行抓取会不会卡顿？**
默认同时抓 4 个站点；低配设备把「最多并行抓取数」调小（如 2）即可降低资源占用。

## 八、安全说明

- 插件运行在 Muvyo 独立沙箱内，代码加密分发，只有安装它的 Muvyo 能解开。
- 只做搜索与返回磁力链接，**不下载内容、不采集账号信息、不执行任意代码**。
- 磁力链接转存 / 离线下载由 Muvyo 平台完成，插件本身不接触你的网盘文件。
- 磁力链接仅保留资源哈希、名称和公网 tracker，不附带任何会让下载器连接额外地址的参数。
